## [2.1.0] — 2026-09-13

### اضافه شد
- 🎨 دکمه‌های رنگی کیبورد پاسخ و دکمه‌های شیشه‌ای با فیلد `style` (Bot API 9.4+): سبز برای انجام، آبی برای اقدام اصلی، قرمز برای حذف و لغو
- 🔄 رابط کاربری سینک‌شده: فهرست‌ها و کارت‌های تسک به‌جای ارسال پیام جدید، درجا ویرایش می‌شوند
- 📋 فهرست تسک‌ها با تب‌های فیلتر (باز / انجام‌شده / همه) و صفحه‌بندی
- 🗂 کارت تسک کامل: بازگشایی تسک انجام‌شده، انتخابگر سریع موعد (امروز/فردا/هفته‌ی بعد)، انتخابگر اولویت و حذف با تایید دو مرحله‌ای
- 🔍 جستجوی عنوان بین تسک‌های کاربر
- 👤 پروفایل آماری: تعداد تسک‌های باز، انجام‌شده، لغو‌شده و درصد پیشرفت
- ⚙️ منوی تنظیمات با خاموش/روشن کردن گزارش روزانه برای هر کاربر
- ⏰ یادآوری خودکار موعد تسک‌ها (فیلد `reminded_at` تا هر تسک فقط یک بار یادآوری شود)
- 🌅 گزارش روزانه‌ی واقعی برای همه‌ی کاربران فعال در زمان `DAILY_REPORT_CRON`
- 🔘 منوی شیشه‌ای داخل پیام (`nav:*`) با دکمه‌ی بازگشت برای همه‌ی صفحات
- 🧪 تست‌های واحد برای کیبوردها، فرمت‌کننده‌ها و محاسبه‌ی موعد

### تغییر کرد
- مهاجرت از `go-telegram-bot-api/v5` (متوقف‌شده) به [`go-telegram/bot`](https://github.com/go-telegram/bot) با پشتیبانی Bot API 10.3
- هندلر آپدیت‌ها با مسیریابی پیشوندی (`nav:`، `list:`، `task:`، `user:`، `settings:`، `state:`) و محافظت از پنیک
- کیبورد اصلی بازطراحی شد: persistent، با placeholder فارسی و دکمه‌های جدید (جستجو، تنظیمات، پروفایل)
- منوی دستورهای بات (`/start`، `/today`، `/new`، `/search`، `/help`) از طریق setMyCommands ثبت می‌شود

### حذف شد
- کتابخانه‌ی قدیمی `go-telegram-bot-api/v5` از وابستگی‌ها

## [2.0.0] — 2026-09-13

### اضافه شد
- دکمه‌های رنگی کیبورد و دکمه‌های شیشه‌ای با استایل Bot API 9.4
- رندر درجا با EditMessageText برای سینک ماندن رابط کاربری
- وب‌هوک تلگرام با اعتبارسنجی `TELEGRAM_WEBHOOK_SECRET`
- دوزبانه شدن رابط کاربری بات (فارسی و انگلیسی)

### تغییر کرد
- مهاجرت به کتابخانه‌ی [go-telegram/bot](https://github.com/go-telegram/bot) با پشتیبانی Bot API 10.3
- بازطراحی کیبورد اصلی: persistent، با placeholder فارسی و دکمه‌های جدید
- ثبت منوی دستورها (`/start`، `/today`، `/new`، `/search`، `/help`)
- به‌روزرسانی ایمیج داکر به Go 1.25

### رفع اشکال
- مهلت پیش‌فرض تسک فقط وقتی اعمال می‌شود که موعدی داده نشده باشد
- مدیریت خطای بررسی‌نشده در کال‌بک انتخاب کاربر
- جلوگیری از پنیک در حلقه‌ی لانگ‌پولینگ
- پیام خطای واضح‌تر و محافظت از واگذاری تسک به خود
