## [2.1.0] — 2026-09-13

### اضافه شد
- 🌐 **بک‌اند پنل وب** — REST API کامل روی همان دیتای بات:
  - تسک‌ها: فهرست (فیلتر وضعیت، صفحه‌بندی، جستجو)، ثبت، بروزرسانی، حذف، تیک و بازگشایی
  - پروفایل و آمار برای داشبورد
- 🔐 **ورود با OTP از طریق بات** — کد ۶ رقمی یک‌بارمصرف توسط بات در تلگرام ارسال می‌شود (هم از وب قابل درخواست است، هم از داخل بات با دکمه‌ی «🌐 اتصال به پنل وب»)
- ⏳ **نشست لغزان ۳۰ روزه** — توکن Bearer با تمدید خودکار هنگام فعالیت؛ کاربر فعال هرگز وسط کار از حساب خارج نمی‌شود
- ✏️ **ویرایش پروفایل از بات** — نام، نام خانوادگی (با پاک‌کردن با «-») و تایم‌زون با اعتبارسنجی
- 🧾 **سیستم لاگ کامل** — خروجی JSON با نمونه‌گیری در پروداکشن، لاگ کوئری‌های کند GORM داخل zap، شناسه‌ی درخواست (X-Request-ID) در همه‌ی لاگ‌های HTTP، لاگ رویدادهای audit (ورود، تغییر پروفایل و…) در جدول ActivityLog
- 🛡 میدل‌ور CORS قابل تنظیم (`WEB_CORS_ORIGIN`) و محدودیت نرخ ۳۰ درخواست/دقیقه روی مسیرهای عمومی ورود
- 📋 کپی کد ورود با دکمه‌ی Copy Text تلگرام

### تغییر کرد
- ساختار پروژه برای توسعه‌پذیری بازآرایی شد: پکیج `bot/ui` جدا شد (کیبوردها، متن‌ها و قرارداد callback)، مخازن به فایل‌های مجزا تقسیم شدند و `httpapi` به هندلرهای متمرکز با تزریق وابستگی شکسته شد
- سرویس‌های احراز هویت و کاربر بین بات و وب مشترک شدند

## [2.0.0] — 2026-09-13

### اضافه شد
- 🎨 دکمه‌های رنگی کیبورد پاسخ و دکمه‌های شیشه‌ای با فیلد `style` (Bot API 9.4+): سبز برای انجام، آبی برای اقدام اصلی، قرمز برای حذف و لغو
- 🔄 رابط کاربری سینک‌شده: فهرست‌ها و کارت‌های تسک به‌جای ارسال پیام جدید، درجا ویرایش می‌شوند
- 📋 فهرست تسک‌ها با تب‌های فیلتر (باز / انجام‌شده / همه) و صفحه‌بندی
- 🗂 کارت تسک کامل: بازگشایی تسک انجام‌شده، انتخابگر سریع موعد (امروز/فردا/هفته‌ی بعد)، انتخابگر اولویت و حذف با تایید دو مرحله‌ای
- 🔍 جستجوی عنوان بین تسک‌های کاربر
- 👤 پروفایل آماری: تعداد تسک‌های باز، انجام‌شده، لغو‌شده و درصد پیشرفت
- ⚙️ منوی تنظیمات با خاموش/روشن کردن گزارش روزانه برای هر کاربر
- ⏰ یادآوری خودکار موعد تسک‌ها (فیلد `reminded_at` تا هر تسک فقط یک بار یادآوری شود)
- 🌅 گزارش روزانه‌ی واقعی برای همه‌ی کاربران فعال در زمان `DAILY_REPORT_CRON`
- 🔘 منوی شیشه‌ای داخل پیام (`nav:*`) با دکمه‌ی بازگشت برای همه‌ی صفحات
- 🧪 تست‌های واحد برای کیبوردها، فرمت‌کننده‌ها و محاسبه‌ی موعد

### تغییر کرد
- مهاجرت از `go-telegram-bot-api/v5` (متوقف‌شده) به [`go-telegram/bot`](https://github.com/go-telegram/bot) با پشتیبانی Bot API 10.3
- هندلر آپدیت‌ها با مسیریابی پیشوندی (`nav:`، `list:`، `task:`، `user:`، `settings:`، `state:`) و محافظت از پنیک
- کیبورد اصلی بازطراحی شد: persistent، با placeholder و دکمه‌های جدید (جستجو، تنظیمات، پروفایل)
- منوی دستورهای بات (`/start`، `/today`، `/new`، `/search`، `/help`) از طریق setMyCommands ثبت می‌شود

### حذف شد
- کتابخانه‌ی قدیمی `go-telegram-bot-api/v5` از وابستگی‌ها

## [1.0.0] — 2026-07-25

### اضافه شد
- ویرایش عنوان و توضیحات تسک از کارت تسک و حذف تسک
- دکمه‌های «پشتیبانی» و «پروفایل» (نام، یوزرنیم، تعداد تسک‌های باز)
- اندپوینت وب‌هوک تلگرام با اعتبارسنجی `TELEGRAM_WEBHOOK_SECRET`
- قرارداد OpenAPI 3.0 و سرو آن روی `/openapi.yaml`
- مستندات فارسی: README، راهنمای معماری و همین CHANGELOG
- الگوی `docker-compose` برای PostgreSQL و ایمیج داکر مینیمال

### تغییر کرد
- بازآرایی کامل ماشین وضعیت مکالمه با توابع جدا برای هر جریان
- یکسان‌سازی ذخیره‌ی وضعیت (۳۰ دقیقه اعتبار، دیتای JSON)
- حذف توکن هاردکدشده از کد؛ توکن فقط از متغیر محیطی خوانده می‌شود
- به‌روزرسانی ایمیج داکر به Go 1.25

### رفع اشکال
- مهلت پیش‌فرض تسک فقط وقتی گذاشته می‌شود که موعدی داده نشده باشد
- مدیریت خطای بررسی‌نشده در کال‌بک انتخاب کاربر
- جلوگیری از پنیک در حلقه‌ی لانگ‌پولینگ
- پیام خطای واضح‌تر و محافظت از واگذاری تسک به خود
